# 🧩 Conseils pour les consoles

## 📶 Un seul Wi-Fi pour tout le monde
Avec la méthode du téléphone, les deux appareils doivent se voir sur le réseau :
`📱 Téléphone ──┐`
`               ├── 📡 Même Wi-Fi`
`🎮 Console ────┘`
Évitez :
- les réseaux Wi-Fi invités ;
- les VPN ;
- le partage de connexion du téléphone ;
- les réseaux qui isolent les appareils entre eux (certains Wi-Fi publics ou d'entreprise).

## 🔁 Le bon ordre pour redémarrer
Si rien n'apparaît :
1. Vérifiez que les deux appareils sont sur le même Wi-Fi.
2. Coupez le VPN.
3. Sur iPhone, vérifiez l'autorisation **Réseau local** de l'application.
4. Redémarrez l'application, puis Minecraft, puis la console.

## 💡 Gagnez du temps
La méthode **Kalium6733** ne demande ni téléphone ni réglage : une fois ajouté en ami, KaLium est toujours dans votre onglet **Amis**.
