# ❓ Problèmes de connexion

## ❌ « Serveur introuvable » ou « Impossible de se connecter »
- **Java** : l'adresse est `Kalium.mine.fun`, sans port.
- **Bedrock** : l'adresse est `91.197.6.68` et le port `40312`. Une adresse Java ne marche pas sur Bedrock, et inversement.
- Mettez Minecraft à jour : une version trop ancienne est refusée.
- Le serveur est peut-être en maintenance : jetez un œil à <#1146795262220705882>.

## 🤝 Kalium6733 n'apparaît pas dans mes amis
- Il accepte les demandes tout seul, mais cela peut prendre quelques minutes.
- Vérifiez que Minecraft est bien connecté à votre **compte Microsoft**.
- Après **15 jours** sans venir sur KaLium, il vous retire de ses amis : ajoutez-le de nouveau.
- S'il ne répond toujours pas, passez par une autre méthode du fil de votre plateforme.

## 📱 La console ne voit pas le téléphone
- Téléphone et console sur le **même Wi-Fi** (pas de Wi-Fi invité ni de partage de connexion).
- Coupez le **VPN** du téléphone.
- Sur iPhone : autorisez le **Réseau local** pour l'application (Réglages › l'application).
- Laissez l'application ouverte jusqu'à être arrivé sur KaLium.

## 🔧 Le DNS ne fait rien
- Vérifiez le DNS de **votre** console : `104.238.130.180` sur Xbox et Switch, `45.55.68.52` sur PlayStation.
- Redémarrez la console après l'avoir changé.
- Rejoignez bien un des serveurs partenaires cités dans le fil de votre console.
